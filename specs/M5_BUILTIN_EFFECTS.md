# SPEC: M5 内置插件扩展（效果器链）

状态: Accepted | 里程碑: M5 | 依据: AGENTS.md §13（M5 内置插件扩展）、ADR-0003（编译前置/实时分离）、ADR-0007（L1 内置插件用 C# DSP）、M2 自动化框架、M3 插件实例表先例
拍板: 2026-11-16 D1=a EQ+压缩+延迟+FDN 混响；D2=a 通道内串联；D3=a 复用 M2 lane；
D4=a 工程内 JSON 预设；D5=a FDN+金属噪声；D6=a 整链统一延迟补偿+上报

## 目标

在引擎内建**自研 C# 效果器**（非 CLAP 宿主路径），形成通道内效果链：

- 内置效果器实例化、串联（通道 → 效果链 → 总线）、参数可调可自动化；
- 全 DSP 自研（无新第三方依赖），RT 零分配、确定性；
- 效果链随工程持久化（顺序 + 参数 + 预设）。

## 完成定义（草案）

- 内置效果器 ≥4 种（见 D1），headless 全链出声 + 黄金基线；
- 效果链顺序/旁路/参数持久化（.weft 往返等价）；
- 效果参数可上自动化 lane（复用 M2 框架，D3）；
- 实时零分配断言（RtAssert）；
- 三平台 CI 绿。

## 架构边界（继承）

```
Domain        Channel.EffectChain（效果器 id 序列 + 每级参数 + lane）
Abstractions  RenderPlan 效果节点表（EffectNode[]：类型/参数/增益曲线）
Engine        效果节点实例表（RCU 换表）+ 逐节点 DSP（零分配、预分配缓冲）
Application   编译器：效果链 → plan 效果节点（顺序固定、参数内联）
```

## 关键设计

- **效果链位置（D2）**：通道内串联（通道源 → 效果 1..n → 通道增益 → 总线）。
  效果节点在 plan 中为纯数据（类型 + 参数值 + 增益断点），引擎侧按节点表实例化
  DSP（与 M3 插件实例表同构的 RCU 换表）。
- **参数自动化（D3）**：效果参数复用 M2 的 AutomationLane 框架——lane 目标扩展到
  "效果器参数"（EffectTarget 扩展 AutomationTarget），编译为节点增益断点，
  引擎在块内按断点插值（与通道曲线同路径）。
- **延迟对齐（D2 附属）**：带 lookahead/延迟的效果器需报告延迟样本数，
  编译期并入通道/全局延迟补偿（PDC 分阶段：M5 先做"整链统一延迟 + 记录上报"，
  不做逐样本 PDC）。
- **预设（D4）**：工程内以 JSON 参数快照存 presets/（同 M3 state chunk 思路），
  不引入 .fxp 第三方格式。

## 竖切节奏（草案）

1. **效果框架竖切**：效果节点表 + 引擎 DSP 宿主 + 一个效果器（3 段均衡 EQ）
   + 黄金基线 + 零分配断言。
2. **效果链竖切**：多效果串联、旁路、延迟对齐、链顺序持久化。
3. **参数自动化竖切**：效果参数 lane（AutomationTarget 扩展）+ 参数面板 UI。
4. **预设与体验竖切**：预设存取、效果面板 UI（旁路/顺序调整/参数）。

## 非目标

CLAP 导出（内置效果器供外部宿主使用——另立专项，需 native shim + C# DSP 互操作）、
卷积混响（需 IR 资产与卷积引擎）、动态 EQ/频谱显示、侧链、并行链、
第三方 VST3/LV2 效果器接入（M3 CLAP 路径已覆盖）、插件 UI 嵌入（高危）。

## 风险

- **延迟对齐**：多效果串联的延迟不一致 → 统一延迟 + 记录（M5 不做逐样本 PDC）；
- **RT 分配**：效果器内部缓冲必须预分配（Reverb/Compressor 状态随实例池化）；
- **参数自动化插值路径**：效果参数曲线复用通道曲线机制，避免两套插值实现；
- **确定性**：效果器状态跨块演化确定（无随机/无时间依赖），黄金基线可复现；
- **质量**：EQ/压缩的曲线拐点与时间常数需可听验证（基线 + 人工试听）。
