本模块为纯文档目录 specs/，按里程碑切分三份独立规格：
- M0_FOUNDATION.md：仓库治理（GPL-3.0、CONTRIBUTING）、native miniaudio shim + CMake、C# Abstractions/Engine/Adapters.Audio.Miniaudio/weftone CLI 的最小可出声地基，以及三平台 CI 矩阵与 RtAssert 零分配断言。
- M1a_HEADLESS.md：headless 竖切，定义 .weft zip 工程格式（ADR-0006）、ProjectDocument 富对象模型、ICommand 撤销、DocumentCompiler → RenderPlan 编译管线、dr_wav 解码 + 线性重采样、CLI `weftone project render/info`，并以 PPQ=96 整数 tick 保证确定性。
- M1b_UI.md：Avalonia 单窗口 UI，严格遵循 headless 优先——App 是唯一引用 Avalonia 的项目，ViewModels 纯 C# 可 headless 单测；通过 PlaybackService 在 UI 线程同步编辑、停止-交换-恢复交付不可变 RenderPlan 给音频线程，Piano Roll/Playlist/Mixer 自绘于 DrawingContext。
三份规格均引用 AGENTS.md §13 与对应 ADR（0002/0003/0004/0006）作为依据，形成「规范 → 实现」的单向依赖方向。
