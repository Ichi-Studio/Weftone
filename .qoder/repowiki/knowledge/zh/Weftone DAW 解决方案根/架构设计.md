根目录作为跨子模块的编排层：
- `Weftone.slnx`（SolutionX）集中声明 `/src/` 下的分层项目（Abstractions → Domain → Application → Engine → Adapters.* → App）、`/tests/` 下的 NUnit 测试与黄金音频回归、以及 `tools/HeadlessRender` CLI。
- `Directory.Build.props` 将全仓统一为 net10.0、Nullable + ImplicitUsings + TreatWarningsAsErrors，并在 Debug 配置自动注入 `RT_ASSERT` 宏，供 C++ 原生层与上层断言共享。
- `Directory.Packages.props` 启用 Central Package Management，集中锁定 NUnit 5、NetArchTest、Avalonia 11 与 CommunityToolkit.Mvvm 等跨测试/UI 子模块复用的包版本。
- `.github/workflows/ci.yml` 在 windows/ubuntu/macos 三平台并行执行：先 `cmake --build native/build` 编译原生 shims，再 `dotnet build/test -c Release|Debug`，最后用 HeadlessRender 跑 m0 冒烟 WAV 尺寸校验与 demo 工程渲染，形成从原生到 .NET 的全链路验证。
- 子模块之间通过 Abstractions 接口解耦（Domain/Application/Engine/Adapters/App），native_bindings 仅暴露稳定 ABI 给 Adapters.Codecs/Miniaudio，测试套件对每层分别断言依赖方向。
