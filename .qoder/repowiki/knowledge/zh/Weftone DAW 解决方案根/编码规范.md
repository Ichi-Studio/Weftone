- 所有 .csproj 继承根 `Directory.Build.props`，统一使用 net10.0、Nullable enable、ImplicitUsings enable 与 TreatWarningsAsErrors。
- NuGet 包版本集中在 `Directory.Packages.props` 中通过 CentralPackageManagement 管理，子项目不直接写版本号。
- Debug 配置下自动定义 `RT_ASSERT` 宏，Release 需显式 `-p:DefineConstants=RT_ASSERT` 叠加，供 C++ 原生与 .NET 侧共享。
- 项目按 Abstractions → Domain → Application → Engine → Adapters.* → App 的分层组织，测试与工具放在独立的 tests/ 与 tools/ 目录。
